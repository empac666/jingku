# Jingku 1.0.4 real Android layout renders

60 PNGs: 15 states × zh/en × light/dark, 1233×2673. Production XML, themes and shared renderer, Robolectric 4.17 + Roborazzi 1.76.0, native Skia (SDK35), deterministic fake data; no HTML. Reproduce: `bash release/scripts/render-1.0.4-screenshots.sh`. The new index-migration state uses the production localized message and dialog actions; about/crash text names 1.0.4/270M, result fixture demonstrates both sides of the recalibrated warning threshold. Earlier 1.0.3 sets are preserved. Visually inspected English light migration/results and Chinese dark attribution. These are layout renders, not physical-device inference tests. Full hashes in release/out/eval270-screenshots.json.
